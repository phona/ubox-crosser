# PR 前自动检查

执行 `gh pr create` 或用户要求创建 PR 前，**必须先完成以下检查**。在同一消息中并行启动所有检查：

## 检查项

| # | 检查 | 执行方式 | 阻塞级别 |
|---|------|---------|---------|
| 1 | 代码审查 | Agent(`code-reviewer`) | 非阻塞（建议） |
| 2 | 安全扫描 | Agent(`Explore`) — 硬编码密钥、注入、未校验输入 | 阻塞（高风险时） |
| 3 | 编译+Lint | `go build ./... && go vet ./... && test -z "$(gofmt -l .)"` | 阻塞 |
| 4 | 测试 | `go test -short ./...` | 阻塞 |

## 执行方式

在**一条消息**中同时发出 2 个 Agent 调用 + 2 个 Bash 调用（共 4 个并行）。等待全部返回后汇总。

## 汇总报告

```
## PR 前检查报告
| 检查项 | 状态 | 详情 |
|--------|------|------|
| 编译+Lint | ✅/❌ | ... |
| 测试 | ✅/❌ | ... |
| 代码审查 | ✅/⚠️ | ... |
| 安全扫描 | ✅/🔴 | ... |
### 结论：🟢 可创建 PR / 🔴 有阻塞项需修复
```

## 阻塞规则

- 编译/Lint/测试失败 → **阻塞**，必须修复后重新检查
- 安全扫描发现高风险 → **阻塞**，必须修复
- 代码审查建议 → **非阻塞**，列出供参考
- 有阻塞项时禁止执行 `gh pr create`
