# OpenSpec Agents

## analyze-agent
- **Role**: Full E2E delivery of REQ
- **Responsibilities**:
  - Write OpenSpec artifacts (proposal, contract, spec)
  - Implement feature code
  - Write unit and integration tests
  - Open PR with complete deliverables
  - Ensure all artifacts are complete before handoff to review/accept phases

## review-agent
- **Role**: Code review and PR validation
- **Responsibilities**:
  - Review implementation against spec
  - Verify test coverage
  - Approve or request changes

## accept-agent
- **Role**: Acceptance testing
- **Responsibilities**:
  - Run acceptance scenarios
  - Validate against specification contracts
  - Confirm feature meets requirements
