## Why

README.md 缺少版本记录，用户无法快速了解项目各版本的变更内容和发布时间。添加版本记录章节让用户和贡献者可以追踪项目演进历史。

## What Changes

- 在 README.md 末尾新增 `## Version History` 章节
- 每条版本记录包含：版本号、发布日期、变更描述
- 版本记录按时间倒序排列（最新版本在前）
- 使用 Markdown 表格或列表格式呈现

## Capabilities

### New Capabilities
- `readme-version-history`: 在 README.md 中添加结构化的版本记录章节，包含版本号、日期和变更说明

### Modified Capabilities

## Impact

- 仅影响 README.md 文件
- 无代码变更、无 API 变更、无依赖变更
