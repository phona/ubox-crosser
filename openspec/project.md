# ubox-crosser OpenSpec Project

A proxy server for managing network connections with authentication and encryption support.

## Project Overview

This project uses OpenSpec for spec-driven development, ensuring all capabilities have contracts and acceptance scenarios documented before implementation.

## Key Capabilities

- **Proxy Server**: TCP-based proxy with shadowsocks encryption support
- **Build Information**: Expose build metadata via HTTP /buildinfo endpoint
- **Controller Management**: Handle client connections and routing
